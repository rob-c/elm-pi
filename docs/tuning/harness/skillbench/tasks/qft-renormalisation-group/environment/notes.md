# QCD running at leading order: inputs and conventions

## Inputs

- alpha_s(m_Z) = 0.1180 at m_Z = 91.1876 GeV, in the five-flavour theory.
- MS-bar quark masses: m_c(m_c) = 1.27 GeV, m_b(m_b) = 4.18 GeV,
  m_t(m_t) = 162.5 GeV. u, d and s are massless.
- m_tau = 1.77686 GeV.

## Conventions

- One loop for the coupling and for the masses, MS-bar:

      mu d(alpha_s)/d(mu) = - (beta_0 / (2 pi)) alpha_s^2,    beta_0 = 11 - 2 n_f / 3
      mu d(m_q)/d(mu)     = - (2 alpha_s / pi) m_q

- Variable flavour number: a quark is active above mu = m_q(m_q). Coupling and
  masses are continuous there, as they are at this order.
- Lambda for n_f flavours is defined by

      alpha_s(mu) = 2 pi / (beta_0 ln(mu / Lambda)).
